# AI Lead Scoring & Sales Follow-up System

An AI-powered lead scoring system for EdTech businesses that predicts
lead conversion probability and helps sales teams prioritize follow-ups.

## Project Status

🚧 Currently under development.

## Problem

EdTech companies receive leads from multiple channels, but sales teams
often lack an intelligent way to prioritize which leads should be
contacted first.

## Goal

Build an end-to-end AI system that:

- Predicts lead conversion probability
- Classifies leads as Hot, Warm, or Cold
- Provides explainable predictions
- Recommends follow-up actions
- Provides a sales dashboard
